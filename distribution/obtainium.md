# Obtainium
Obtainium tracks an APK from a web page or direct link and notifies you of updates.
- Source: **Direct APK link**, URL `https://linkedoutnetwork.com/dl/apk` (always the latest live release; counted as a download).
- One-tap add link (shown on /install): `obtainium://add/https://linkedoutnetwork.com/dl/apk`
- Because Obtainium installs the APK itself, Android still checks it is signed with the same certificate as the installed app.
- Test this once on a real phone before announcing it; Obtainium's version-detection options differ between releases.
