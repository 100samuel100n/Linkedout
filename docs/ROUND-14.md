# Round 14 (web)

* **Company dashboard is its own workspace** (`components/company-suite/Dashboard.jsx`): sidebar + top bar, no feed navigation. `components/Shell.jsx` renders it bare.
* **Live now**: presence is self-healing (creates its table if missing, never fails because of the rate limiter or geo lookup), logs failures, counts recent signed-in activity as "other", and the panel prints diagnostics when it shows zero. The root cause on your server wasn't reproducible from the code alone; if it still shows 0, the panel now says why.
* **Premium application messaging** (`components/jobs/ApplicationChat.jsx`, used by candidates and recruiters): day dividers, grouped bubbles, read receipts, timeline events, interview cards, document requests, link attachments, quick-reply templates, optimistic send, live refresh.
* **Admin**: Jobs now has queues (needs review / reported / awaiting company / closing soon), a full job record (transparency, trust and safety, engagement, reports, audit trail, applications as counts only), and actions (approve, remove, pause, reopen, trust level, link company, extend deadline, mark external, import external jobs, notes, delete). Companies has queues (verification pending, paying, needs attention, suspended), plan/jobs/team/dispute/report columns, and the record shows hiring and enterprise settings.
* **Previously "coming soon", now built**: company SSO with OpenID Connect + SCIM 2.0, audit-log retention, SSO session length, size and place peer cuts, hiring teams, bulk job actions, CSV job import, promoted jobs (separate labelled slot, never changes organic rank), resume upload, calendar (.ics) files, "is hiring" hint under stories, external job import (admin).
* **Still not built**: SAML (needs XML signature verification; OIDC covers Entra ID, Google Workspace and Okta), native Workday/Greenhouse/Lever connectors (API + webhooks cover them), storing the original resume file (only the extracted text is kept, on purpose).
